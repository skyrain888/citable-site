Citable 隐私政策

适用于 Citable 浏览器插件（Chrome / Edge）· 生效日期：2026-10-06 · 版本 1.0

一句话说明

插件的检测在你的浏览器本地完成。我们不收集你用插件检测的网址、域名、页面内容、API Key 或任何能识别你身份的信息。只有在你主动同意后，才会发送匿名的功能使用统计，并且可以随时关闭。在本网站首页使用「在线检测」时，你输入的网址需要发送到我们的服务器才能检测，处理方式见下文「网站上的在线检测」。

插件在本地处理的数据

  • 当前网页的内容与 robots.txt / llms.txt / sitemap.xml：仅在你点击插件时读取当前标签页，用于在本地计算检测结果，不会上传。
  • 最近一次检测结果：保存在浏览器会话存储中，用于「完整报告」页面，关闭浏览器后自动清除。
  • 你的设置：包括你选择的 AI 服务商、接口地址、API Key 和模型，只保存在本机（chrome.storage.local），不会同步，也不会发给我们。

可选功能：AI 改写建议

如果你配置了自己的 AI 服务商并点击「AI 改写建议」，插件会把检测结果和当前页面的正文（最多约 12,000 字符）直接从你的浏览器发送到你选择的服务商（例如 Anthropic、OpenAI、DeepSeek，或你自建的服务）。这部分数据由该服务商按其隐私政策处理，不经过我们的服务器。

匿名使用统计（需要你主动同意）

安装后，欢迎页会询问你是否允许发送匿名使用统计。默认不发送；同意后才开始，随时可以在插件「设置 → 隐私」中关闭，关闭后立即停止并清空未发送的数据。

会发送不会发送
  • 功能使用事件：打开插件、完成检测、复制修复代码、展开某项检查、修改页面类型、打开完整报告、对结论的「准确 / 不准确」反馈、AI 改写是否成功
  • 检测结果的概要：分数与等级、页面类型、被挡住 / 受限的平台数量、未通过的检查项编号
  • 环境信息：插件版本、浏览器（Chrome / Edge）、操作系统类型、界面语言、安装天数
  • 随机生成的匿名安装 ID（与账号无关）
  • 你检测的网址、域名、页面标题、页面内容
  • 你的浏览记录、按键、鼠标轨迹、剪贴板内容
  • API Key、账号、邮箱等身份信息
  • 精确地理位置

如果你在安装后没有在欢迎页做选择，插件会在第一次检测结果的底部再询问一次，同样默认不发送。

用途：仅用于了解功能是否有用、发现误判、决定后续开发什么（产品改进与产品分析）。不会出售数据，不会用于广告或用户画像，不会转给数据经纪商。

IP 地址：统计请求发送到产品分析服务时，网络连接本身不可避免会带有你的 IP 地址；该服务已设置为丢弃客户端 IP，因此不会存储 IP，也不会据此推算位置。

处理方：统计数据由我们使用的产品分析服务（PostHog）代为存储和处理。数据保留不超过 12 个月。

卸载问卷

卸载插件后，浏览器会打开一个可选的问卷页面，地址中只包含插件版本号和安装天数。是否填写由你决定。提交后，你选择的原因和填写的文字会以匿名方式发送到上述产品分析服务（同样不记录 IP），用于改进产品。请不要在文字中填写个人信息。

反馈页面

当你在插件中点「告诉我们哪里不准」时，会打开一个反馈页面。你填写的反馈类型和文字会以匿名方式发送到上述产品分析服务（同样不记录 IP）。只有当你在页面上主动填写网址或联系方式时，我们才会收到这些信息；这些都是可选的。

本网站的访问统计

本网站（产品介绍页与数据报告页）会以匿名方式记录页面访问和安装按钮点击，内容只有：访问的是哪个页面、来源网站的域名、链接中的渠道参数（utm_source 等），以及点击了哪个商店的安装按钮。不使用 cookie，不在浏览器中保存任何标识，不建立用户档案；数据发送到上述产品分析服务（同样不记录 IP）。

网站上的在线检测

在本网站首页使用「在线检测」时，你输入的网址会发送到我们的服务器（位于新加坡），由服务器以普通访问的方式读取该网页及其 robots.txt 等公开内容进行检测。检测结果只在服务器内存中缓存最多 1 小时，用于加速重复查询，不写入磁盘，也不和任何身份关联。为防止滥用，服务器会按访问者 IP 限制检测频率，IP 只在内存中短暂计数，不会记录或保存。统计只记录检测是否完成和分数段，不记录网址。

Chrome Web Store 用户数据政策

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.
